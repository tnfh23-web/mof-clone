# 해양수산부 홈페이지 클론 코딩

해양수산부 홈페이지를 참고해 HTML, CSS, JavaScript로 구현한 학습용 프로젝트입니다. 해양수산부의 공식 서비스가 아닙니다.

- 배포: https://tnfh23-web.github.io/mof-clone/
- 참고 사이트: https://www.mof.go.kr/index.do

## 구현 내용

- 클릭으로 여는 헤더 메뉴, 2차 메뉴, 전체메뉴
- 슬라이드 이전·다음 및 자동재생 정지·재생
- 이달의 해양수산 탭과 자주찾는 메뉴 탭
- 팝업 닫기, 화면 크기 조절
- WebP 이미지와 지연 로딩을 이용한 초기 로딩 개선

링크는 클론 코딩용으로 `#`을 사용합니다. 검색은 외부 페이지로 이동하지 않으며, ‘오늘 열지 않기’ 저장 기능은 구현하지 않았습니다.

## 실행

별도 빌드 없이 정적 웹 서버로 실행할 수 있습니다.

```bash
python -m http.server 5500
```

브라우저에서 `http://localhost:5500`에 접속합니다.

## 배포

GitHub Pages가 기본 브랜치의 루트 디렉터리를 배포합니다. 커밋을 GitHub에 푸시하면 배포가 자동 갱신됩니다. `.nojekyll`로 정적 파일을 그대로 제공합니다.

## 사용 기술 및 자료

HTML, CSS, JavaScript, jQuery, Swiper, Pretendard GOV를 사용했습니다. 이미지와 로고 등 원본 사이트의 자료에 대한 권리는 해당 권리자에게 있습니다.
